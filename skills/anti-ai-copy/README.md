# anti-ai-copy

有温度的中英文写作技能。

来源：[howaboua-pi-stuff/packages/pi-skill-anti-ai-copy](https://github.com/IgorWarzocha/howaboua-pi-stuff)（MIT）

保持作者声音的 prose 起草、改写和审校。适用于产品文案、文档、README、邮件、帖子、个人简介、论文、UI 文本，或去除 AI/企业腔调。

## 安装

```bash
bun run install
```

## 使用

在项目中使用 `/skill-selector` 选择技能，或在对话中描述写作/改写需求，由 LLM 加载。

## 内容

- `skills/anti-ai-copy/SKILL.md` — 技能主文件（7 条原则 + 工作流）
- `references/trope-checklist.md` — AI 腔调常见套路清单

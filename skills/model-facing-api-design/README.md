# model-facing-api-design

面向模型的工具契约设计技能。

来源：[howaboua-pi-stuff](https://github.com/IgorWarzocha/howaboua-pi-stuff)（MIT）

pi 工具契约设计：名称、描述、schema、prompt 元数据、结果、错误、截断、恢复、token 成本。用于工具设计、审查或选择/调用失败分析。

## 安装

```bash
bun run install
```

## 内容

- `skills/model-facing-api-design/SKILL.md` — 技能主文件
- `scripts/tool-token-lines.mjs` — 工具 token 行数分析脚本

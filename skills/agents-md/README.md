# agents-md

AGENTS.md 编写与维护技能。

来源：[howaboua-pi-stuff/packages/pi-skill-agents-md](https://github.com/IgorWarzocha/howaboua-pi-stuff)（MIT）

范围化的 AGENTS.md 编写与维护：仓库级、嵌套级、全局或个人指令；规则修剪；范围定位；或将 agent 指引与 README/docs 分离。

## 安装

```bash
bun run install
```

## 使用

在项目中使用 `/skill-selector` 选择技能，或在对话中描述需要创建/维护 AGENTS.md 的需求，由 LLM 加载。

## 内容

- `skills/agents-md/SKILL.md` — 技能主文件
- `references/agents-md-guide.md` — AGENTS.md 编写指南
